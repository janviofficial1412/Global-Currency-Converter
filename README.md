# Global-Currency-Converter

A simple and responsive **Currency Converter Web Application** built as my first project while learning web development.

This project was created primarily to strengthen my understanding of **JavaScript** by applying what I learned to a real, working application.

## ## 🚀 Live Demo

[**Try the Live Demo →**](https://janviofficial1412.github.io/Global-Currency-Converter/)


## 📌 About the Project

The Currency Converter allows users to enter an amount, select a source currency, select a target currency, and get the converted amount using **live exchange-rate data from an API**.

The project also updates the corresponding country flags when currencies are changed.

## ✨ Features

* 💰 Enter an amount to convert
* 🌎 Select from multiple currencies
* 🔄 Select the target currency
* 🚩 Dynamic currency flags
* 📡 Fetches exchange-rate data through an API
* ⚡ Instant conversion
* 📱 Responsive and modern UI
* 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

* **HTML** – Structure of the application
* **CSS** – Styling, layout, and responsive design
* **JavaScript** – DOM manipulation, events, API handling, and conversion logic
* **Currency API** – Exchange-rate data
* **Flags API** – Currency/country flags

## 🔌 APIs Used

### Currency API

Exchange-rate data is fetched using:

`https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@latest/v1/currencies/`

### Flags API

Currency flags are displayed using:

`https://flagsapi.com/`
